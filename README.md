# Proyecto Brokeback

## ¿Porqué Kanban?

- Metodología ágil y visual para llevar a cabo la planificación de un proyecto.
- Tarea que acabo, tarea que cojo, ordenadas pro prioridad
- Utilizamos un tablero para organizar las tareas:
    - Backlog -> Pendientes de creación
    - Ready -> Creadas, pero pendientes de asignar
    - In progress -> En progreso
    - In review -> En revisión tras su finalización

---

## ¿Porqué no Scrum?

- Se planifican por semanas, mucho menos ágil que la Kanban
- Todavía no tenemos la experiencia para planificar semanalmente, kanban nos ayuda a priorizar de una manera más sencilla
